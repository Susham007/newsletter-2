The session never properly began. So we read the record it did leave behind: **7,825 parliamentary questions**, filed over 19 sitting days across both Houses.

The archive is not a perfect measure of political intent, but it is a precise record of attention. In a session shaped by an exam-paper leak and an escalating student-welfare crisis, only four questions addressed suicide, mental health, or ragging.

## What the record shows

Most questions asked for counts, allocations, or implementation updates. Only 78 tested whether a scheme had worked. The imbalance matters because a question can do more than request a number: it can expose a failure, require a minister to answer publicly, and build the evidence for oversight.

This analysis treats every question as a signal of priority. Read together, those signals show a Parliament rich in activity but thin on evaluation.
